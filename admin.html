Add photographs

Drop JPEG, PNG or WebP files here, or choose them. Each keeps its own aspect ratio. Camera settings are read from the file where present; location data is removed.

Categories

These appear as filters along the top of your gallery, in this order. A photograph can belong to several. Categories with no photographs are hidden on the public site.

Learn section

Lessons appear on your home page in this order, and each opens in its own reader. The section is hidden when there are no lessons.

Formatting lesson text

Leave a blank line between paragraphs. Then:

## Heading starts a new section

- item on each line makes a list

1. step on each line makes a numbered list. Lessons with six or more headings get an "In this lesson" contents list automatically

> text makes a large pull quote

**bold** and *italic*

Quick check questions: start each question with Q:, then one answer per line. Mark the right answer with * and wrong ones with -.

[[photo:Title of photo]] on its own line shows one of your gallery photographs in the lesson

[[shot:Title of photo]] shows the photograph with its place, camera, lens and settings, for Behind the shot

Site details

Your signature is used as the logo. The name is used for the browser tab, search results and screen readers. Leave About empty to hide that section.

Instagram posting

Tick Share to Instagram on a photograph and publish. Twice a week (Tuesday and Friday evening) the next one in the queue is posted automatically, in the order the photographs appear in your list. The caption is built from the title, place, year, description and settings, then the link and hashtags below. Setup steps are in the README.

Hashtags for each category. A post gets the tags above plus those for each category the photograph is in, up to Instagram's limit of 30.

Connect to GitHub

This page saves straight to your site's GitHub repository. You need a fine-grained access token that can only touch this one repository.

  1. On GitHub, open Settings → Developer settings → Personal access tokens → Fine-grained tokens and choose Generate new token.
  2. Under Repository access pick Only select repositories and choose your site's repository.
  3. Under Permissions → Repository permissions set Contents to Read and write. Leave everything else as it is.
  4. Generate it, copy it, and paste it below.

The token is stored only in this browser on this device. Use Forget token on shared computers.
